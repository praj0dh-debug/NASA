# Evaluation & Learning Outcomes Measurement Plan

## Objective
To quantify learning gains in STEM and aerospace physics concepts rather than merely recording game session engagement.

## Metrics
1. **Pre/Post Learning Gain ($\Delta$ Score)**
   - Initial pre-test knowledge vs. post-simulation evaluation debrief score.
   - Benchmark: Minimum +25% score gain post-flight.

2. **Simulation Iteration & Resilience Index**
   - Number of redesign attempts before achieving stable orbit (measures student testing & iterative refinement per NGSS-3-5-ETS1-3).
   - Expected average: 1.8 iterations per cadet.

3. **Curriculum Standards Mastery Rate**
   - Percentage of classroom roster achieving $\ge 70\%$ on NGSS-aligned quizzes.
   - Target benchmark: $\ge 85\%$ mastery across elementary cohorts.

4. **Session Duration & Completion Velocity**
   - Average scenario time: 12 to 18 minutes.
